Local File Sharing for Android is a native Android app that packages [Local File Sharing](https://github.com/MahinBro001238/LocalFileSharing/) into a proper Android application. Instead of setting up Termux and running the server manually, you just open the app, enter a password, and the server starts. The app runs the server as a foreground service so it keeps going in the background, and shows a persistent notification while it is active. When you want to stop it you just tap stop in the app

This app requires Android 16 or higher and is only compatible with arm64-v8a devices
